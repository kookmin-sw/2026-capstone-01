포스터

프로젝트 소개

Krip은 외국인 여행자가 자신의 취향과 조건에 맞는 관광지를 빠르게 탐색하고, 여행 일정을 구성하며, 함께 여행할 메이트를 찾을 수 있도록 지원하는 서비스입니다.

위치 기반 관광지 검색, 즐겨찾기, 맞춤 일정 생성, 수동 일정 작성, 여행 메이트 모집, 친구 관리, 실시간 채팅, 피드 공유 기능을 제공합니다.

LOCALIZED

한국 환경에 최적화된 로컬 관광지 및 맛집 데이터를 제공합니다.

ACCESSIBLE

언어와 식문화 장벽을 줄이는 여행 편의 기능을 제공합니다.

PERSONALIZED

사용자 취향과 위치를 반영한 맞춤형 여행 코스를 추천합니다.

SOCIAL

여행 메이트 연결과 실시간 채팅 기능을 지원합니다.

문제 정의

  • 한국어 메뉴판 및 안내판 이해의 어려움
  • 글로벌 지도 서비스의 한국 로컬 데이터 부족
  • 비건·할랄·알러지 음식 정보 접근성 부족
  • 현지인 및 동행자 연결 어려움
  • 접근성 정보 부족으로 인한 여행 불편

해결 방안

AI 메뉴판 번역

Gemini API 기반 OCR 및 번역을 통해 메뉴 정보를 다국어로 제공합니다.

위치 기반 탐색

한국 로컬 데이터를 기반으로 주변 관광지 및 맛집을 추천합니다.

맞춤 여행 일정

여행 스타일, 예산, 일정 조건을 반영해 AI 기반 일정을 생성합니다.

여행 메이트 매칭

온보딩 데이터와 취향 분석 기반으로 유사 여행자를 추천합니다.

타겟 사용자

  • 서울을 처음 방문한 20~30대 외국인 자유여행객
  • 로컬 경험을 원하는 외국인 관광객
  • 여행 동행자를 찾고 싶은 사용자
  • 식문화 및 언어 접근성이 필요한 관광객

주요 기능

위치 기반 관광지 탐색

거리·평점·리뷰 수 기준으로 관광지를 탐색할 수 있습니다.

맞춤 여행 일정 생성

여행 기간, 예산, 여행 스타일 기반 개인화 일정을 생성합니다.

수동 여행 일정 작성

추천 기능 없이도 사용자가 직접 여행 일정을 구성하고 관리할 수 있습니다.

여행 메이트 모집

선호 성별·연령대 기반으로 여행 메이트를 모집할 수 있습니다.

실시간 채팅

친구 요청, 그룹 채팅, 실시간 메시징 기능을 제공합니다.

피드

여행지 속 나의 모습을 보여줄 수 있습니다.

핵심 기술

  • Google Places API 기반 관광 데이터 수집
  • AI + RAG 기반 여행 추천
  • Gemini API 기반 OCR 및 번역
  • Firebase 기반 실시간 알림 시스템

유저 플로우

01

회원가입 / 로그인

이메일 또는 Google OAuth로 가입 후, 온보딩에서 여행 스타일·선호 음식·접근성 정보를 입력합니다.

02

관광지 탐색

현재 위치 기반으로 주변 관광지 및 맛집을 거리·평점·카테고리 필터로 탐색하고 즐겨찾기에 저장합니다.

03

AI 메뉴판 번역

식당에서 메뉴판을 카메라로 촬영하면 Gemini OCR이 메뉴를 인식하고 영어로 번역하여 설명과 가격을 제공합니다.

04

여행 일정 생성

여행 기간·예산·스타일을 입력하면 AI가 맞춤 일정을 자동 생성합니다. 수동으로 직접 작성하는 것도 가능합니다.

05

여행 메이트 모집 / 매칭

모집 게시글을 작성하거나, 취향이 비슷한 여행자를 추천받아 친구 요청을 보냅니다.

06

실시간 채팅 & 피드 공유

친구 또는 그룹 채팅으로 여행 계획을 조율하고, 피드에 여행 사진과 일정을 공유합니다.
