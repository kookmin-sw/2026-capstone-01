KRIP은 어떤 서비스인가요?

PROBLEM

외국인 여행자가 겪는 불편함

2024년 방한 외국인 1,893만 명 — 하지만 여전히 많은 여행자가 정보 접근성 문제로 불편을 겪습니다.

01
메뉴판 언어 장벽
한국어 메뉴판 및 안내판을 이해하기 어려워 주문·이용에 어려움을 겪습니다.
02
로컬 데이터 부족
글로벌 지도 서비스는 한국 로컬 맛집·관광지 데이터가 부정확하거나 부족합니다.
03
식문화 정보 부재
비건·할랄·알러지 음식 정보에 대한 접근성이 낮아 식사 선택이 어렵습니다.
04
동행자 연결 어려움
혼자 여행하는 외국인이 현지인이나 동행자를 찾을 수 있는 플랫폼이 없습니다.
05
접근성 정보 부족
교통·시설 접근성 정보 부족으로 장애인·고령 여행자가 불편을 겪습니다.
06
맞춤 일정 계획 부재
취향·예산·일정에 맞는 개인화 여행 계획을 세울 수 있는 도구가 없습니다.
SOLUTION

KRIP의 해결 방안

🍽️
AI 메뉴판 번역
Gemini API 기반 OCR 및 번역으로 메뉴 정보를 다국어로 즉시 제공합니다.
🗺️
위치 기반 탐색
한국 로컬 데이터를 기반으로 주변 관광지·맛집을 실시간 추천합니다.
📅
맞춤 여행 일정
여행 스타일·예산·일정 조건을 반영해 AI가 최적의 일정을 생성합니다.
🤝
여행 메이트 매칭
온보딩 데이터와 취향 분석 기반으로 유사 여행자를 자동 추천합니다.

TECH

핵심 AI 기술

최신 AI 모델과 클라우드 인프라로 구동되는 KRIP의 기술 기반입니다.

Google Gemini 2.5 Flash
메뉴판 OCR 인식 및 VLM 기반 이미지 분석으로 다국어 번역을 지원합니다.
RAG 기반 여행 추천
LangChain + LangGraph를 활용한 RAG 파이프라인으로 개인화 여행 일정을 생성합니다.
Google Places API
한국 로컬 관광지·맛집 데이터를 활용하여 정확한 위치 기반으로 추천하여 제공합니다.
Firebase FCM
실시간 푸시 알림 시스템으로 채팅·여행 메이트 요청을 즉시 전달합니다.
USER FLOW

이렇게 사용해요

01
회원가입 / 로그인
이메일 또는 Google OAuth로 가입 후, 온보딩에서 여행 스타일·선호 음식·접근성 정보를 입력합니다.
02
관광지 탐색
현재 위치 기반으로 주변 관광지 및 맛집을 거리·평점·카테고리 필터로 탐색하고 즐겨찾기에 저장합니다.
03
AI 메뉴판 번역
식당에서 메뉴판을 카메라로 촬영하면 Gemini OCR이 메뉴를 인식하고 영어로 번역해 설명과 가격을 제공합니다.
04
여행 일정 생성
여행 기간·예산·스타일을 입력하면 AI가 맞춤 일정을 자동 생성합니다. 수동으로 직접 작성하는 것도 가능합니다.
05
여행 메이트 모집 / 매칭
모집 게시글을 작성하거나, 취향이 비슷한 여행자를 추천받아 친구 요청을 보냅니다.
06
실시간 채팅 & 피드 공유
친구 또는 그룹 채팅으로 여행 계획을 조율하고, 피드에 여행 사진과 일정을 공유합니다.
